# Scripting API reference (`robotics_api`)

Generated by `tools/gen_api_docs.py` from the docstrings in `robotics_api/`. Do not edit
`docs/api-reference.md` by hand: change the docstring or `tools/api_docs/*.md`, then run
`python tools/gen_api_docs.py`. `python tools/gen_api_docs.py --check` exits 1 when the file is stale.

Code: `robotics_api/` (top-level package next to `app/`), runner `app/script_runner.py`, console dock
`app/panels/script_panel.py`, examples `examples/*.py`, user guide `docs/user-guide.md`.

Import: `import robotics_api as api`. The repo root and `bindings/` must be on `sys.path`
(the app and the tests do this; for a standalone script set `PYTHONPATH` to the repo root and `bindings/`).

## Version and compatibility rule

`robotics_api.__api_version__ = "1.1"` (`MAJOR.MINOR`, semantic; 1.1 added `export_urdf` and
`generate_report`):

-   MINOR (1.0 -> 1.1): additive only (new function, new optional argument, new key in a returned dict,
    new attribute). A script written for `1.x` keeps working on every later `1.y`.
-   MAJOR (1.x -> 2.0): may remove or change behaviour. Scripts check `api.__api_version__`.
-   Not part of the API: anything starting with `_`, and every module under `app/` or `core_bridge`.

The API takes and returns plain Python and numpy types only (lists, dicts, `float64` arrays, strings).
Every error is a `RoboticsApiError` (see Errors); raw bridge exceptions never leak.

## Units and conventions

Metres, radians, seconds, newtons, newton metres, kilograms. Poses are 4x4 homogeneous matrices in
the WORLD frame (base pose included). A joint vector has one entry per DOF (`robot.n_dof`):
radians for revolute, metres for prismatic joints; fixed and mimic joints are not DOFs. Gravity default
`[0, 0, -9.81]` m/s^2 (world vector).

Shape and obstacle poses accept a 4x4 matrix, `{"xyz": [...], "rpy": [...]}` or 3 / 6 numbers
(m, rad, URDF roll-pitch-yaw). Shape `size`: box `[x, y, z]` m, sphere radius m, cylinder / capsule
`[radius, length]` m.

Every public name in `robotics_api.__all__` is listed below. Each entry shows the signature

## Project and files

### `new_project`

A new empty project (not saved).

Example:

```python
project = api.new_project("Demo")
```

### `open_project`

```python
open_project(path: str) -> Project
```

Open a .robotproj file. Raises ``ProjectError`` for a missing or damaged file.

Example:

```python
project = api.open_project("cell.robotproj")
print(project.name, project.robot.n_dof)
```

### `save_project`

```python
save_project(project: Project, path: str) -> str
```

Save ``project`` to ``path`` (must end with .robotproj). Returns the path.

Example:

```python
api.save_project(project, "cell.robotproj")
```

### `import_urdf`

```python
import_urdf(path: str, search_roots: list[str] | None = None) -> Robot
```

Import a URDF file and return the ``Robot`` (meshes are resolved next to the file or in
``search_roots``). ``robot.import_report`` holds the warnings. Raises ``ImportFailed`` (with
``.report``) when the file cannot be imported.

Example:

```python
robot = api.import_urdf("examples/planar_2r.urdf")
print(robot.n_dof, robot.joint_names)
```

## Robot

### `Robot`

A robot model with kinematic and dynamic queries.

Create it with ``import_urdf(path)``, ``Project.robot`` or ``Robot.from_json``. The object
owns a snapshot of the model: later edits in the app do not change it.

Example:

```python
T = robot.fk([0.3, -0.4])          # 4x4 TCP pose
J = robot.jacobian([0.3, -0.4])  # (6, n_dof)
```

#### Members

#### `Robot.from_json`

```python
from_json(text: str, name: str = '') -> Robot
```

Robot from a Unified Robot Model JSON string (``Robot.to_json``).

#### `Robot.to_json`

```python
to_json() -> str
```

The Unified Robot Model of the robot as a JSON string.

#### `Robot.copy`

```python
copy() -> Robot
```

Independent copy (new model snapshot, same collision geometry).

#### `Robot.n_dof`

*(property)*

Number of degrees of freedom (non-fixed, non-mimic joints).

#### `Robot.joint_names`

*(property)*

Joint name per DOF, in DOF order (the order of every q vector).

#### `Robot.joint_types`

*(property)*

``"revolute"`` or ``"prismatic"`` per DOF.

#### `Robot.limits`

*(property)*

Position limits, array of shape ``(n_dof, 2)`` = ``[lower, upper]`` per DOF (rad or m).

#### `Robot.collision_shapes`

*(property)*

Collision geometry as plain dicts (``type``, ``link``, ``pose``, size keys).

#### `Robot.set_collision_shapes`

```python
set_collision_shapes(shapes: list[dict]) -> None
```

Replace the robot collision geometry.

Each dict: ``type`` (box / sphere / cylinder / capsule), ``link`` (link index; the
shape pose is in that link frame), ``pose`` (4x4, ``{"xyz","rpy"}`` or 3/6 numbers, m and
rad), ``size`` (box [x, y, z] m; sphere radius m; cylinder, capsule [radius, length] m).

#### `Robot.fk`

```python
fk(q: Any) -> np.ndarray
```

Forward kinematics. ``q``: n_dof values. Returns the 4x4 world pose of the TCP (m).

#### `Robot.jacobian`

```python
jacobian(q: Any) -> np.ndarray
```

Geometric Jacobian of the TCP in the world frame, shape ``(6, n_dof)``.

Rows 0-2: linear velocity (m/s per unit joint speed), rows 3-5: angular velocity (rad/s).

#### `Robot.ik`

```python
ik(pose: Any, seed: Any = None, all_solutions: bool = False, position_only: bool = False, n_starts: int = 30, random_seed: int = 42)
```

Inverse kinematics of a 4x4 world TCP ``pose`` (m).

``seed``: start joint vector (default zeros); solutions are sorted by distance to it.
Solutions respect the joint limits. Returns the nearest solution (array of n_dof) or
``None`` when there is none; with ``all_solutions=True`` a list of arrays (maybe empty).
``position_only`` ignores the orientation. ``n_starts`` random restarts, ``random_seed``
for them.

#### `Robot.inverse_dynamics`

```python
inverse_dynamics(q: Any, qd: Any, qdd: Any, gravity: Any = None) -> np.ndarray
```

Joint torques (N.m, N for prismatic) that produce ``qdd`` at ``(q, qd)``.

``gravity``: world gravity vector in m/s^2 (default [0, 0, -9.81]).

#### `Robot.forward_dynamics`

```python
forward_dynamics(q: Any, qd: Any, tau: Any, gravity: Any = None) -> np.ndarray
```

Joint accelerations (rad/s^2, m/s^2) for the applied torques ``tau`` (N.m, N).

#### `Robot.mass_matrix`

```python
mass_matrix(q: Any) -> np.ndarray
```

Joint space mass matrix M(q), shape ``(n_dof, n_dof)``, symmetric positive definite.

#### `Robot.energy`

```python
energy(q: Any, qd: Any, gravity: Any = None) -> dict
```

Mechanical energy in joules: ``{"ke", "pe", "total"}``.

``pe = -sum m g.p_com`` for the world gravity vector (default [0, 0, -9.81]).

#### `Robot.manipulability`

```python
manipulability(q: Any) -> float
```

Yoshikawa manipulability of the full 6-row TCP Jacobian: product of its singular
values (mixed units: m and rad). 0 at a singular pose.

## Motion

### `Trajectory`

A timed joint trajectory through waypoints.

``times``: strictly increasing seconds starting at 0. ``waypoints``: array ``(n, n_dof)``.
``interpolation``: ``"linear"`` or ``"cubic"`` (clamped spline, zero speed at both ends).
``q(t)``, ``qd(t)``, ``qdd(t)`` return arrays of n_dof; ``t`` is clamped to the duration.
After ``time_parametrize``: ``ok`` is True when the limit check found no violation and
``report`` is its text.

Example:

```python
traj = api.Trajectory([0.0, 1.0], [[0.0, 0.0], [0.5, -0.5]], interpolation="cubic")
print(traj.q(0.5))
```

#### Members

#### `Trajectory.n_dof`

*(property)*

Number of joints (columns of each waypoint).

#### `Trajectory.duration`

*(property)*

Duration in seconds.

#### `Trajectory.interpolation`

*(property)*

Interpolation name: 'linear' or 'cubic' (as given to the constructor).

#### `Trajectory.times`

*(property)*

Waypoint times in seconds, shape (n,).

#### `Trajectory.waypoints`

*(property)*

Waypoint joint vectors, shape (n, n_dof).

#### `Trajectory.q`

```python
q(t: float) -> np.ndarray
```

Joint vector at time ``t`` (s); clamped to the trajectory ends.

#### `Trajectory.qd`

```python
qd(t: float) -> np.ndarray
```

Joint velocity at time ``t`` (rad/s or m/s).

#### `Trajectory.qdd`

```python
qdd(t: float) -> np.ndarray
```

Joint acceleration at time ``t`` (rad/s^2 or m/s^2).

#### `Trajectory.sample`

```python
sample(dt: float) -> dict
```

Samples every ``dt`` seconds (last sample at the duration): dict ``t, q, qd, qdd``.

### `time_parametrize`

```python
time_parametrize(path: Any, robot: Robot, vmax: Any = None, amax: Any = None, interpolation: str = 'cubic') -> Trajectory
```

Timed trajectory through the waypoints of ``path`` (array ``(n, n_dof)``, rad or m).

``vmax`` (rad/s or m/s) and ``amax`` (rad/s^2) per DOF or scalar; default the joint velocity
limits (1 where none) and 2. Segment times are scaled up until no velocity or acceleration
limit is violated. Cubic interpolation falls back to linear when the spline would leave the
joint limits. Returns a ``Trajectory`` (``ok``, ``report``).

Example:

```python
traj = api.time_parametrize(path, robot)
print(traj.duration, traj.ok)
```

### `plan`

```python
plan(robot: Robot, start: Any, goal: Any, obstacles: list | None = None, planner: str = 'rrt_connect', seed: int = 0, time_limit: float = 5.0, resolution: float = 0.02, shortcut: bool = True) -> np.ndarray
```

Collision free joint space path from ``start`` to ``goal``.

``start``: n_dof joint values (rad or m). ``goal``: n_dof joint values or a 4x4 TCP pose
(inverse kinematics solutions become the goals). ``obstacles``: list of dicts
``{"type": "box" | "sphere" | "cylinder", "pose": ..., "size": ...}`` in the world frame
(pose: 4x4, ``{"xyz","rpy"}`` or 3 / 6 numbers in m and rad; size: box [x, y, z] m, sphere
radius m, cylinder [radius, length] m). The robot collision geometry comes from the imported
URDF (or ``Robot.set_collision_shapes``). ``planner``: rrt_connect, rrt_star or prm.
``seed``: same seed, same path. ``time_limit`` in s, ``resolution`` = edge check spacing in
rad. Returns an array ``(n_points, n_dof)``, start first, goal last. Raises ``PlanningError``
when no path is found.

Example:

```python
path = api.plan(robot, [0.0, 0.0], [2.2, 0.3], planner="rrt_connect", seed=1)
print(len(path))
```

### `simulate`

```python
simulate(robot: Robot, control: Any = None, duration: float | None = None, dt: float = 0.001, integrator: str = 'rk4', q0: Any = None, qd0: Any = None, gravity: Any = None, record_every: int = 1, kp: Any = None, kd: Any = None) -> dict
```

Simulate the robot dynamics and return the recorded signals as arrays.

``control``: ``None`` (zero torque), a constant torque vector (N.m), a callable
``tau = f(t, q, qd)`` (numpy arrays in, n_dof torques out), or a ``Trajectory`` (computed
torque tracking with gains ``kp``, ``kd``, default 100 and 20). ``duration`` in s (default
the trajectory duration). ``dt`` in s. ``integrator``: euler, rk4 or rk45. ``q0``/``qd0``:
initial state (default zeros, or the first trajectory point). ``gravity``: world vector
(default [0, 0, -9.81]). ``record_every``: keep every n-th step.

Returns a dict of numpy arrays: ``t`` (N,) and ``q, qd, qdd, tau`` (N, n_dof) plus
``tcp_pos`` (m), ``tcp_quat`` (w,x,y,z), ``tcp_vel`` (m/s), ``ke, pe, total`` (J),
``power`` (W per DOF), ``power_sum``, ``sigma_min``, ``manipulability``: the same signals
as the Recorder of the app (see docs/simulation.md). Sample 0 is the initial state.

Example:

```python
res = api.simulate(robot, None, duration=1.0, dt=0.001, q0=[0.8, 0.0],
                   gravity=[0.0, -9.81, 0.0], record_every=10)
print(res["total"][-1])
```

## Analysis and export

### `workspace`

```python
workspace(robot: Robot, n_samples: int = 200000, voxel: float | None = None, seed: int = 42, metrics: bool = False) -> dict
```

Monte Carlo workspace of the TCP position (CPU).

``n_samples`` random joint vectors inside the joint limits (all limits must be finite);
``voxel``: voxel edge in m (default reach / 100); ``seed``: random seed; ``metrics=True``
adds per-voxel singular-value and manipulability statistics. Returns a dict of numpy arrays
and numbers: ``volume`` (m^3, voxel count x voxel^3), ``volume_err_bound`` (m^3), ``filled``
(voxel count), ``voxel_size`` (m), ``origin`` (m, grid corner), ``dims`` (grid size),
``n_samples``, ``keys`` (linear voxel index), ``count`` (samples per filled voxel) and
``centers`` (filled, 3) voxel centres in the base frame (m). Cancel-aware.

Example:

```python
ws = api.workspace(robot, n_samples=100000, voxel=0.05)
print(ws["volume"])
```

### `export_csv`

```python
export_csv(result: dict, path: str, names: list[str] | None = None, meta: dict | None = None) -> int
```

Write the ``simulate`` result to a CSV file (time column ``t [s]`` plus one column per
signal entry, units in the header, metadata in ``#`` comment lines). Returns the row count.

Example:

```python
api.export_csv(res, "swing.csv", names=["q", "tcp_pos"])
```

### `export_npz`

```python
export_npz(result: dict, path: str, names: list[str] | None = None, meta: dict | None = None) -> int
```

Write the ``simulate`` result to a compressed NPZ file (``<name>_t``, ``<name>``, JSON
``meta``). Returns the row count.

Example:

```python
api.export_npz(res, "swing.npz")
```

### `export_urdf`

```python
export_urdf(robot: Robot, path: str, copy_meshes: bool = True) -> dict
```

Write the robot as a URDF file (R8.3). DH joints are converted to origin/axis; link
visuals and collision shapes are written; mesh files found on disk are copied to a
``meshes`` folder next to ``path`` and referenced by relative paths.

Returns ``{"path": str, "meshes": [relative mesh paths], "warnings": [str]}``.

Example:

```python
info = api.export_urdf(robot, "out/robot.urdf")
print(info["warnings"])
```

### `generate_report`

```python
generate_report(robot: Robot, path: str, result: dict | None = None, workspace_result: dict | None = None, plan: Any = None, fmt: str | None = None) -> dict
```

Write a robot report (R8.3) as HTML or PDF; ``fmt`` ("html" / "pdf") defaults to the
file extension of ``path``.

Sections: summary, joint table, DH or origin/axis table, mass and COM; optional:
``workspace_result`` (the dict returned by ``workspace``), ``result`` (the dict returned by
``simulate``: graphs), ``plan`` (a path array from ``plan``: length). A missing optional
section is left out and named in the returned ``missing`` list.

Returns ``{"path": str, "format": str, "pages": int | None, "missing": [str]}``.

Example:

```python
info = api.generate_report(robot, "report.pdf", result=res)
print(info["pages"])
```

## Errors

### `RoboticsApiError`

Subclass of `Exception`.

Base class of all API errors.

### `InvalidArgument`

Subclass of `RoboticsApiError, ValueError`.

A bad argument: wrong shape, wrong number of joints (n_dof), non-finite value, bad name.

### `ProjectError`

Subclass of `RoboticsApiError`.

A project file cannot be read, written or has a bad format.

### `ImportFailed`

Subclass of `RoboticsApiError`.

A robot file (URDF) cannot be imported. ``report`` holds the import report text.

### `ComputationError`

Subclass of `RoboticsApiError`.

A numerical computation failed (kinematics, dynamics, IK).

### `SimulationError`

Subclass of `RoboticsApiError`.

The simulation failed (for example the mass matrix is not positive definite).

### `PlanningError`

Subclass of `RoboticsApiError`.

No collision free path was found, or the planner could not start.

### `AnalysisError`

Subclass of `RoboticsApiError`.

A workspace or other analysis failed.

### `ExportError`

Subclass of `RoboticsApiError`.

Data cannot be written to a file.

### `ScriptCancelled`

Subclass of `RoboticsApiError`.

The script was cancelled (cooperative cancel, see ``check_cancel``).

### `ScriptTimeLimit`

Subclass of `ScriptCancelled`.

The script ran into the time limit setting.

## Script runner (`app/script_runner.py`)

`ScriptRunner(task_runner, project_provider=None, time_limit=None)`: `run_string(code, name)`, `run_file(path)`,
`cancel()`, `is_running`; signals `started()`, `output(text, is_err)` (one line), `finished(status, message)` with
status `ok` / `error` / `cancelled` / `timeout` (message = traceback for `error`). One script at a time; the
script runs in a `TaskRunner` worker thread, the GUI stays responsive. The script namespace has
`robotics_api` (also `api`) and `app`, a read-only snapshot: `has_project`, `project_name`, `project_path`,
`robot` (a `Robot` copy or None), `q` (current joint vector), `version`. For `run_file`, `__file__` is set and the
script folder is on `sys.path` while it runs. Output uses thread-aware stdout / stderr: only writes made by the
script thread are captured, the app's own output is untouched (streams are restored when the script ends,
even if the script replaced them). A script exception never leaves the runner. Setting: `time_limit` seconds
(default None).

UI: View -> Script console (dock, hidden at start: editor, Run, Cancel, output); File -> Run script... (file
dialog). Output also goes to the log panel (`[script]` / `[script stderr]`).

Security: the namespace is not a sandbox. Scripts run in the application process with full Python rights.

## Examples

`examples/fk_sweep.py` (FK sweep), `examples/plan_and_simulate.py` (plan around a box, time parametrize,
simulate the tracking), `examples/export_data.py` (simulate and export CSV and NPZ). They use
`examples/planar_2r.urdf`. Run them from a shell with the repo root and `bindings/` on `PYTHONPATH`, or from
the script console (it sets `__file__`).

## Cancel behaviour

`simulate`, `plan` and `workspace` call `check_cancel()` often and raise `ScriptCancelled` when the runner asked
to stop (Cancel button, or the time limit -> `ScriptTimeLimit`). A script with its own long loop calls
`api.check_cancel()` inside the loop. `api.is_cancelled()` tests without raising. Outside the runner these are
no-ops. The token is thread-local: threads started by the script are not cancelled. A script stuck in pure
Python code that never calls the API cannot be stopped.

## Error notes

-   `InvalidArgument` is also a `ValueError`.
-   `ScriptTimeLimit` is a subclass of `ScriptCancelled`.
-   The original exception is kept as `__cause__` of the API error.

# Dynamics validation

Independent check of the app kinematics and dynamics against **MuJoCo 4.0.1**.

Generated by `tools/validate_dynamics.py` (backend `mujoco`, 20 seeded random samples per robot, seed 0, q within joint limits, qd and qdd standard normal, gravity (0, 0, -9.81)).

## How to run

```
python -m pip install mujoco
python tools/validate_dynamics.py --backend mujoco
```

Options: `--robots ur5 panda` (names under `robots/`), `--urdf FILE` (extra URDF), `--samples N`, `--seed S`, `--out FILE`.

## What is compared

- FK: world pose (4x4) of every link frame that exists on both sides (max abs element error).
- Jacobian: 6 x n at the TCP link origin, world-aligned, rows [linear; angular] (MuJoCo `mj_jac`).
- Mass matrix M: app `mass_matrix` vs `mj_fullM`.
- tau: app `inverse_dynamics(q, qd, qdd, g)` vs `mj_rne` with qacc (RNEA, includes Coriolis and gravity).
- g: gravity torque (qd = qdd = 0).

Tolerances: FK 1.0e-10 m, Jacobian / M / tau / g 1.0e-09 relative (max abs error divided by max(1, max abs reference)).

## Setup notes

- URDF is preprocessed: visual, collision and dynamics elements are removed (only kinematics and inertials matter); the same file is loaded by the app importer and MuJoCo.
- MuJoCo compiler: `fusestatic=false`, `discardvisual=true`, `balanceinertia=false`, `inertiafromgeom=false`; damping, armature, frictionloss set to 0; constraints, contacts and limits disabled.
- Joints are matched by name. Mimic joints are made fixed (locked at 0) on both sides; the mimic master stays a normal DOF. A mimic equality constraint is not used.

## Pinocchio (optional)

Pinocchio has no Python 3.13 Windows pip wheel, so it runs in a separate conda env. The `pinocchio` backend calls `tools/_pinocchio_worker.py` with that env's python (JSON in, JSON out). **This backend could not be tested here** (no pinocchio in the dev environment).

```
micromamba create -n pin -c conda-forge python=3.12 pinocchio numpy
# or: conda create -n pin -c conda-forge python=3.12 pinocchio numpy
micromamba run -n pin python -c "import sys; print(sys.executable)"
python tools/validate_dynamics.py --backend pinocchio --pinocchio-python C:\path\to\envs\pin\python.exe --out docs/validation/pinocchio-report.md
```

## LOW (fix when nearby)

Status (A1.9): fixed in A1.1-A1.7 (A1.1 temp dirs and stale autosave; A1.2 Recover-No, backups, configs; A1.3 plugins_folder; A1.4 and A1.5 C++/CUDA items; A1.6 numerics, planning, import; A1.7 export, report, logger, API, connect-before-submit), except the items marked won't fix (scope 2026-11-13): `_allow_read`, case-insensitive keys and `_uniq`, manifest regex, mesh path confinement, non-sm_120 GPU detection, packaging items.

Data/project:
- `project_controller` Recover "No" deletes autosave before main file is known to load; `_set_project` never clears the discarded project's autosave.
- `migrations.make_backup` never overwrites an existing `.bak` → a second old file with the same name gets no backup.
- `mkdtemp(robotproj_assets_*)` leaks (no close on exit, error paths).
- `configs/store.py from_dict`: one bad entry aborts the whole load.
- `sim/export.py export_csv`: newline in meta value breaks/injects CSV rows; `np.unique` drops duplicate timestamps in the non-aligned path.
- `reports/mesh_export.py`: `counts` keyed by raw name, file by `_safe(name)` → "arm 1"/"arm_1" overwrite.

Plugins:
- `_allow_read` grants the whole parent dir of a picked file.
- QSettings keys are case-insensitive on Windows → "Foo" grant inherited by "foo"; `_uniq` maps `a-b`/`a.b`/`a_b` to one `sys.modules` key.
- `manifest._NAME_RE` ends with `$` → accepts trailing `\n` (use `\Z` / `fullmatch`).
- `plugins_folder` empty string → cwd scanned as plugin folder.

Numerics/planning/import:
- Joint limit `lo>=hi`: planner treats it as unlimited (±π), IK/workspace pin it at 0. URDF `<limit>` without lower/upper imported silently.
- URDF `_vec`/`_num` accept `nan`/`inf`; zero-axis check `norm < eps` is False for NaN.
- `planning/checks.py _runs`: NaN passes every check → "OK".
- Planner `_cancel_fn` reads `is_cancelled` as property, workspace calls it as method → method-style token cancels at once.
- `sim/mode.py finite_difference_torque`: midpoint velocity used at t2 (h/2 lag).
- `sim/playback.py` dynamic speed = speed*time_scale; kinematic ignores time_scale.
- `sim/engine.py stop()` does not reset `integrator.next_dt` (RK45 stale step).
- `cartesian._solve` branch-jump check at k=0 against `q_seed` → false failure.
- Mesh paths (`visuals.py`, `collision._mesh_points`) not confined; project-file paths go to `pv.read` unchecked.

C++/CUDA:
- `parallel.hpp`: thread create failure → `std::terminate`; `n_threads` not clamped.
- `ws_count_bits` raw `cudaMalloc` OOM bypasses host fallback; `sample_q_gpu` throws non-std `Oom`.
- `ensure_pool` init failure leaks 2 streams + 4 events per retry.
- `gpu_manager` does not mark NoKernelImage/UnsupportedPtx/InsufficientDriver as unusable → non-sm_120 GPU fails every call then CPU reruns.
- `ik_multi.cpp`: distribution built before `hi>lo` guard; no finite check on limits.
- `compile()` no `validate()`: duplicate joint names (mimic binds wrong master), non-finite mimic mult/offset.
- IK options unchecked (`damping=0`, huge `max_iter` with GIL released, no cancel).
- LLT on NaN M reports Success → NaN qdd.

API/misc:
- `robotics_api._util`: `vec` accepts numeric strings; `pose4` no orthonormal check; `xyz_rpy` raw ValueError on ragged input.
- `generate_report` pdf creates `QGuiApplication` + `QPdfWriter` in the script worker thread.
- Results/errors connected after `submit_fn` in main_window import, ik_panel, workspace_panel (planning_panel already fixed) → rare lost result, panel stuck `_running`.
- `AppLogger()` adds handlers each time; log dir mkdir unguarded.
- Packaging: spec silently skips missing `.pyd`; `install.ps1` leaves stale files.

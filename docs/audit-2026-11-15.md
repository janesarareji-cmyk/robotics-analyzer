## 7. Features / roadmap (academic value first)

1. **Independent validation on Python 3.12** (Pinocchio in a separate venv/conda env, `tools/_pinocchio_worker.py` exists): FK/Jacobian/RNEA/CRBA vs Pinocchio for the 9 sample robots; a thesis-grade second oracle beside MuJoCo. Highest value per effort.
2. **Via points saved in the project** (session only today) + curve definitions saved: makes the curve work reproducible; needs format 1.5.0.
3. **Normalised manipulability and units** (C4 + G3): results comparable across robots, citable.
4. **Second robot (U3.8)**: two-arm workcell collision + reach overlap; format 1.5.0, `CollisionService` multi-model, second `RobotView` actor set, Joint panel tab. Large.
5. **Base placement study**: grid of base poses, score = reachable targets with valid ranked IK + mean normalised sigma_min; uses existing `rank_solutions` and overlays. Strong academic result.
6. **GPU Jacobian** (P1): makes Fine quality overlays interactive.
7. Later / out of scope unless asked: CAD import, task builder, robot code export.
